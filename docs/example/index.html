Study outline: US county economics

This outline is a data study you can run with turbolapper on a Mac, using the public county bundle documented in this repository. It states the question, the data, and the analysis path. Record the findings from the run you do in turbolapper.

The five steps match the turbolapper method. Applicants for the 2027 scholarship can use this shape. Details and deadline: see turbolapper.com.

Question

Pick one decision and write it in a sentence. The test question canon lists questions a study can start from. Three that show the range:

  • Which 10 counties had the fastest GDP growth in 2022?
  • Which counties in Texas are boomtowns? In this bundle, a boomtown is a county in the top quartile of both GDP growth and population growth for that year.
  • Which counties are energy dominant? The published flag treats mining and energy above 25 percent of county GDP as energy dominant.

Answer one of these, or a question of your own, with the file analyzed in turbolapper.

Data

Four public-domain US government sources feed the county tables. Counts below are the ones recorded in this repository.

Sources in the US county economics bundle
Source Dataset Years Counties
BEA CAGDP2, GDP by county and industry 2001 to 2024 3,126
BEA CAINC1, personal income, population, and per-capita income 1969 to 2024 3,148
IRS Statistics of Income, AGI and wages by county 2015 to 2022 3,203
Census Bureau Population Estimates Program, population and migration 2020 to 2024 3,143

Use 2022 for a first pass. That year overlaps BEA GDP, BEA income, and IRS tax data. Census population and migration cover 2020 to 2024. The wide table semantic.county_all_flags holds 3,253 counties and county-equivalents. Household metrics divide income and GDP by IRS filing units, a household proxy. A boolean flag is NULL when the series for that county-year is missing.

The geography catalog lists FIPS codes. Travis County, Texas is 48453. Los Angeles County, California is 06037. The schema reference defines every column. The repository README describes the DuckDB file the build produces. The build pipeline is under sources/.

The schema reference also documents BLS consumer price and average retail price tables for metro areas. Those tables use BLS area codes. County tables join on FIPS, so the price tables stay in their own geography.

Local analysis on your Mac

  1. Install turbolapper

    Use the turbolapper download page. AFM needs macOS 27 with Apple Intelligence. Medium needs macOS 26 or later and 16 GB. The dataset stays on the Mac in both editions.

  2. Bring the county file onto the Mac

    Keep the source name and the vintage of the file next to the question.

  3. Prepare documented views

    Clean names and joins once. semantic.county_all_flags is the documented starting point for most county questions. Join on fips and year. The technology page calls this prep heavy, run light: how Local Analytics works.

  4. Ask the question in turbolapper

    Follow-up questions stay on the flat monthly or annual price. Starter is free, with a data cap. See turbolapper pricing.

  5. Read the confidence label

    turbolapper uses Verified, Estimated, and Directional. When coverage is thin, keep that label with the claim.

Findings

Write each claim in a sentence. Include the county, the year, the metric, and the confidence label. Name the source table. Where a flag is NULL, say the series is missing.

The known unknowns list topics this bundle leaves open: poverty rates, unemployment, rural and urban codes, cost of living, housing affordability, and education attainment. A finished study names those limits when the question touches them.

Publish

A finished study carries the question, the sources and years, the turbolapper edition, a note that the analysis ran on a Mac, the findings with confidence labels, and the questions the tables leave open. The published product path ends in a slide deck. Read that path on the turbolapper technology page.
